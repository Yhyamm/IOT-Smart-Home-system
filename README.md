# IOT-Smart-Home-system
Here is a simple protoype of an IOT smart home system using ESP32 microcontroller and a set of sensors to monitor the house condition and run an alert in case of fire. I created the monitoring app using BLYNK platform, the code was made in Arduino IDE.
